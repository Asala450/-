# Дәрігерге жазылу жүйесі

Зертханалық жұмыс №6: HTTP және Fetch API.

## Жоба туралы

Бұл веб-бет пайдаланушыға дәрігерге жазылуға арналған форма береді. Пайдаланушы аты-жөні мен email енгізіп, "Пайдаланушыны жіберу" батырмасын басады. Деректер Fetch API арқылы серверге жіберіледі, ал жауап бетте көрсетіледі.

## Қолданылған технологиялар

- HTML
- CSS
- JavaScript (Fetch API)
- PHP

## Жобаның құрылымы

```
index.php   - басты бет және форма
script.js   - Fetch API арқылы сұраныс жіберетін код
```

## Қалай іске қосу керек

1. Жобаны жүктеп алыңыз:
```
   git clone https://github.com/Asala450/-.git
```
2. Жоба папкасын XAMPP-тың `htdocs` папкасына салыңыз.
3. XAMPP-та **Apache** серверін қосыңыз.
4. Браузерде `http://localhost/жоба-папкасының-аты/index.php` сілтемесін ашыңыз.
